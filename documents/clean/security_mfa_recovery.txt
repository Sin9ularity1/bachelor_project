Northstar Industries
MFA Recovery
Document status: Approved
Classification: Internal
Document ID: NS-013
Department: Security
Version: 1.0

1. Purpose
This procedure establishes the Northstar Industries requirements for mfa recovery. It applies to employees and relevant approved contractors.

2. Requirements
2.1 A lost MFA device can be reset only after service-desk identity verification.
2.2 An emergency MFA recovery code remains valid for 15 minutes.

3. Responsibilities
The security function maintains this document and records exceptions through the normal approval workflow. Employees must follow the requirements stated above.

4. Related guidance
This document addresses mfa recovery. Other Northstar Industries procedures may cover related but distinct workflows. In the event of uncertainty, employees should consult the responsible department.
