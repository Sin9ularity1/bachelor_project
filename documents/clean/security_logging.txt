Northstar Industries
Security Logging
Document status: Approved
Classification: Internal
Document ID: NS-019
Department: Security
Version: 1.0

1. Purpose
This procedure establishes the Northstar Industries requirements for security logging. It applies to employees and relevant approved contractors.

2. Requirements
2.1 Security event logs are retained for 180 days.
2.2 Only the security lead may disable centralized security logging during approved maintenance.

3. Responsibilities
The security function maintains this document and records exceptions through the normal approval workflow. Employees must follow the requirements stated above.

4. Related guidance
This document addresses security logging. Other Northstar Industries procedures may cover related but distinct workflows. In the event of uncertainty, employees should consult the responsible department.
