Northstar Industries
Physical Access Security
Document status: Approved
Classification: Internal
Document ID: NS-020
Department: Security
Version: 1.0

1. Purpose
This procedure establishes the Northstar Industries requirements for physical access security. It applies to employees and relevant approved contractors.

2. Requirements
2.1 Lost access badges must be reported immediately.
2.2 After-hours visitor entry requires authorization from the site security supervisor.

3. Responsibilities
The security function maintains this document and records exceptions through the normal approval workflow. Employees must follow the requirements stated above.

4. Related guidance
This document addresses physical access security. Other Northstar Industries procedures may cover related but distinct workflows. In the event of uncertainty, employees should consult the responsible department.
