Northstar Industries
Data Classification
Document status: Approved
Classification: Internal
Document ID: NS-016
Department: Security
Version: 1.0

1. Purpose
This procedure establishes the Northstar Industries requirements for data classification. It applies to employees and relevant approved contractors.

2. Requirements
2.1 Information is classified as Public, Internal, Confidential, or Restricted.
2.2 Only the data owner with security approval may downgrade a Restricted document.

3. Responsibilities
The security function maintains this document and records exceptions through the normal approval workflow. Employees must follow the requirements stated above.

4. Related guidance
This document addresses data classification. Other Northstar Industries procedures may cover related but distinct workflows. In the event of uncertainty, employees should consult the responsible department.
