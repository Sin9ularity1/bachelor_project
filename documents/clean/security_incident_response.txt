Northstar Industries
Incident Response
Document status: Approved
Classification: Internal
Document ID: NS-012
Department: Security
Version: 1.0

1. Purpose
This procedure establishes the Northstar Industries requirements for incident response. It applies to employees and relevant approved contractors.

2. Requirements
2.1 Suspected security incidents must be reported immediately after discovery.
2.2 The incident commander coordinates severity-one security incidents.

3. Responsibilities
The security function maintains this document and records exceptions through the normal approval workflow. Employees must follow the requirements stated above.

4. Related guidance
This document addresses incident response. Other Northstar Industries procedures may cover related but distinct workflows. In the event of uncertainty, employees should consult the responsible department.
